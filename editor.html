GitHub-Schlüssel
  1. Öffne github.com/settings/personal-access-tokens/new.
  2. Name z. B. „Lagekarte“, Ablaufdatum wählen.
  3. Repository access: Only select repositories → weltkarte.
  4. Permissions → Repository → Contents: Read and write.
  5. „Generate token“, kopieren und hier einfügen.
Der Schlüssel bleibt nur in diesem Browser gespeichert.
